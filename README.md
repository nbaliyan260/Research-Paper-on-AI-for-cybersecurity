## 🔬 Research Topics Covered

- **LLM Security**: Prompt injection, jailbreaking, unlearning, data poisoning
- **RAG Security**: Retrieval-Augmented Generation attacks and defenses
- **Software Security**: Vulnerability detection, fuzzing, code analysis
- **AI-Powered Attacks**: Phishing, social engineering, adversarial ML
- **Privacy & Unlearning**: Federated unlearning, machine unlearning
- **Model Attribution**: Fingerprinting, watermarking, IP protection
- **Malware Analysis**: AI-driven malware detection and classification
